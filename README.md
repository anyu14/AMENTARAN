# Amentaran

> Plataforma web de apoyo y acompañamiento emocional.

**Estado:** Proyecto personal en desarrollo.

Amentaran nace con el objetivo de crear un espacio digital seguro, cercano y accesible donde las personas puedan compartir sus experiencias, encontrar contenido de apoyo y sentirse acompañadas.

La plataforma está pensada para ofrecer recursos de bienestar emocional y facilitar la conexión entre usuarios dentro de una comunidad moderada.

## Objetivo del proyecto

Muchas personas atraviesan momentos difíciles sin saber dónde expresar lo que sienten o encontrar información accesible.

Amentaran busca reunir en una misma plataforma:

- Un espacio para compartir historias y experiencias.
- Contenido relacionado con el bienestar emocional.
- Comunicación entre usuarios.
- Moderación para proteger a la comunidad.
- Acceso al contenido en español y catalán.

## Funcionalidades desarrolladas

- Registro e inicio de sesión.
- Autenticación mediante JWT.
- Creación y publicación de historias.
- Sistema de moderación de contenido.
- Chat en tiempo real.
- Interfaz adaptable a diferentes dispositivos.
- Contenido disponible en español y catalán.
- Gestión de usuarios y permisos.

## Arquitectura

El proyecto está dividido en dos partes principales:

- `cliente`: interfaz desarrollada con React.
- `servidor`: API y lógica del Back-End desarrolladas con Flask.

El Front-End se comunica con la API REST para gestionar usuarios, autenticación, historias y contenido. Socket.IO permite incorporar comunicación en tiempo real.
